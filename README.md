# Pluscord — catálogo de distribuição

Catálogo experimental de plugins em português brasileiro. O projeto é independente e não oficial. Este repositório público contém somente arquivos de distribuição; o desenvolvimento fica separado.

Endereço do catálogo: https://raw.githubusercontent.com/guilhermeopd7/Pluscord/main/index.json

**Estado inicial:** nenhum plugin publicado. O catálogo será preenchido exclusivamente com pacotes compilados, verificados por SHA-256 e aprovados para distribuição. Não há APK, credenciais ou código-fonte privado neste repositório.
